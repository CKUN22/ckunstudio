# CKUN STUDIO · 免费测试版部署

目标地址：**https://ckun.cc/ckunstudio**。API：`/ckunstudio/api/`。使用现有 Cloudflare Pages 项目 `gerenzhan`，由首页 `/` 的“团队协作”按钮提供入口，直接跳转 `/ckunstudio/`；`/CK_STUDIO/` 不再放置协作入口。

2026 年 11 月 13 日已发布免费测试版，并验证正式域名页面及接口正常。首次使用请按下文创建团队。

## 当前方案

采用 Pages Functions + D1，不需要 R2 订阅，也不需要独立服务器或持续开机的电脑。账号、任务、BUG、思路及小图附件均保存于 D1。字体默认微软雅黑。

- 每条最多 5 张图片，每张最多 512KB。
- 大图在浏览器内自动缩放并转为 WebP，再上传；小图保留原文件。
- 图片仍需登录读取，不放在公开静态资源目录。
- 标题、详情、执行人、状态、优先级、截止日期、搜索及统计功能不变。
- 每 6 秒同步列表；版本号和原子条件更新防止并发覆盖。

R2 虽有免费使用额度，但需开通订阅结算且超额收费，因此此版没有启用 R2。D1 免费计划的当前额度是每天 500 万行读取、10 万行写入、账户共 5GB 存储，单个免费数据库最大 500MB。免费额度用尽时请求受限，不会自动升级付费。Pages Functions 也受账号免费请求和运行额度约束。实际以账号套餐及 Cloudflare 最新规则为准。

官方来源：[D1 定价](https://developers.cloudflare.com/d1/platform/pricing/)、[D1 限制](https://developers.cloudflare.com/d1/platform/limits/)、[R2 开通要求](https://developers.cloudflare.com/r2/get-started/)。

## 发布与首次使用

在个人站目录运行 `npm run build`，通过既有 Git 集成发布，或使用：

```powershell
npx wrangler pages deploy dist --project-name gerenzhan --branch master
```

不要仅上传静态 ZIP：Pages Functions 需要由 Wrangler 或 Git 构建处理。发布后访问 `/ckunstudio`，使用 `.env.ckunstudio.production` 中 `STUDIO_SETUP_KEY` 的值创建第一个账号。随后由队长进入“团队管理”，生成邀请，让另外两位成员各自注册。

公开页面首次创建账号受初始化密钥保护，不会被访客抢先创建团队。其他成员需邀请码加入；所有成员共享一个空间，并可编辑、删除团队记录。

## 本地验证

仅使用本地模拟资源，不触碰线上数据：

```powershell
npm run build
npx wrangler d1 migrations apply STUDIO_DB --local --config wrangler.studio.local.jsonc
npx wrangler pages dev dist --port 8790 --d1 STUDIO_DB=00000000-0000-0000-0000-000000000001 --binding STUDIO_AUTH_SECRET=local-development-only-not-a-production-secret-2026 --binding STUDIO_SETUP_KEY=local-setup-key-do-not-use-in-production --compatibility-date 2026-11-13
```

本地入口：`http://localhost:8790/ckunstudio`。当前 Pages 不接受自定义配置路径，因此本地开发通过参数指定绑定；迁移使用本地配置。示例密钥只用于本地测试，不可写入生产环境。`.wrangler/` 为模拟数据，Git 已忽略。

协作软件目录中的 `node cloudflare/smoke.mjs http://127.0.0.1:8790` 可验证完整流程；脚本禁止对公网地址运行，避免污染线上数据。

## 范围及后续

本版用于 3 人小团队的免费测试，图片压缩会影响原图细节，不能用作源素材仓库。大文件和原始美术资源仍通过现有版本管理工具保存。尚未提供多团队隔离、密码找回、评论和业务编辑历史。

原 Node.js 本地版的数据不会自动迁移到云端。生产团队由用户自行首次初始化；本地测试账号不会上传。

- 升级前备份 D1 数据库；先在本地副本验证。
- 将 `cloudflare/site/migrations/studio/0003_p0.sql` 放入个人站的 `migrations/studio`。在个人站目录用现有生产绑定执行 `npx wrangler d1 migrations apply STUDIO_DB --remote`，检查迁移输出后再部署新版站点。
- 既有 D1 团队：按 `created`、`rowid` 排序的首个账号成为唯一队长。迁移后查询 `SELECT id,name,role,active FROM studio_users ORDER BY created,rowid`，确认原创建账号是队长，其他现有成员仍为普通成员。
- 旧永久邀请码会停用。队长登录“团队管理”，生成 1–30 天有效、1–100 次可用的新邀请；新团队初始化提供的首个邀请默认 7 天 / 10 次。
- 移除成员保留账号和历史记录；立即撤销其会话和关注，未完成记录改为未分配并提升版本号，队长需重新分配。
- 通知保存于 D1，全部未读及最近 200 条历史通知可查看。分配、前置完成/重开/删除、关注记录变化触发通知；到期检查在用户打开应用时运行，最多每分钟一次，无额外定时任务或外部通知服务。
- 任务依赖用数据库触发器检查循环，不自动开始下游任务。删除前置任务需确认，会解除对应依赖并通知下游负责人。

P0 真实运行时验证：在独立本地 Pages 服务运行后执行 `node cloudflare/p0-smoke.mjs http://127.0.0.1:8790`。该脚本只接受 localhost，并保留独立测试环境中的历史记录以供检查；不要对生产环境运行。

## 素材标签目录与资源一致性

本次标签扩展无需新 SQL 迁移。必须一起发布 `lib/task-catalog.mjs`、新版 API、前端以及生成的 `public/ckunstudio/task-catalog.js`；`npm run prepare:cloudflare` 会生成并集成这些文件。仅更新页面而遗漏共享模块会导致脚本加载失败。

本地版升级后需重新启动 `node server.mjs` 或 `启动协作软件.cmd`，再刷新浏览器。新版本按进程启动时加载的静态资源提供页面，避免旧 API 与新页面混用。旧标签格式会兼容读取，既有任务不需要重新创建。
